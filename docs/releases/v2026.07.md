# 2026.07 Credit Assignment Map

This release updates the living map of credit assignment in reasoning and agentic LLM reinforcement learning. It combines the July refresh, earlier gap fills, and new repository navigation tools.

## Research Update

- Added GRPO-lambda as a backfilled 2025 core method.
- Added eight 2026 core methods: DelTA, SCRL, TRIAGE, OAR, CRAFT, SC-GRPO, GRAIL, and VPR.
- Added APPO, OPID, and PAPO as near-core optimization methods.
- Added Progress Advantage as a related signal and QVal as an evaluation resource.
- Preserved STARE, Temporal Scheduling for RLVR, and SDAR as related threads outside the main method taxonomy.

## Three Trends

1. **Credit is moving below the trajectory level.** Recent work increasingly reweights tokens, spans, subproblems, and turns instead of broadcasting one sequence advantage.
2. **Counterfactual structure is becoming cheaper to obtain.** Sibling rollouts, self-conditioned solutions, and perturbation proxies reuse training artifacts to estimate local responsibility.
3. **Agentic credit is becoming more verifiable.** Execution feedback, intermediate oracles, and dense-signal evaluation reduce reliance on unrestricted LLM judges.
